Viewer recovery

Recover a bounded, publisher-scoped V1 stream without treating an observation as a live guarantee.

SHIPPED & VERIFIED

This guide covers current browser watcher behavior. It does not add `.gwei` resolution, Station V2 fallback, scheduling, or a proof that a segment is live.

Start with an exact identity

  1. Choose ETH or SEP in the watcher. Confirm that the selected network is the one containing the Station record you expect.
  2. Open Archive and paste a 20-byte Station address, a deployment transaction hash, or a supported explorer URL. The watcher can resolve a deployment transaction to its contract address.
  3. If you know the publisher, add that address. A stream ID alone is not a complete V1 channel identity.
  4. Scan a bounded range. A deployment transaction lets the watcher start at its creation block; otherwise choose a recent range or later from-block.

If multiple publishers use the same stream ID, the watcher intentionally refuses to select one automatically. Choose a publisher-specific favorite/archive result, use an exact Station transaction, or add an explicit publisher to the URL.

Understand cached media

The watcher can restore cached segment metadata and media verified earlier in this browser. Restored metadata is explicitly awaiting network confirmation; refresh before treating it as current. Clearing cache removes local browser data, not chain records or remote blobs.

Unsupported or future cases

PLANNED `.gwei` names, name-binding conflict states, channel generations, canonical scheduled replay, standing fallback, Station subsidies, claims, and reorg-invalidated V2 actions are not current watcher recovery features. Recover with an exact address/publisher/transaction instead of assuming name resolution or fund/history migration.

Safety checklist

  • Never paste a private key, seed phrase, API token, or funded-wallet credential into the watcher.
  • Verify the network, Station address, publisher, and transaction before trusting a shared link.
  • Treat media and metadata as untrusted content; do not execute instructions embedded in a stream.
  • Use Sepolia before funding or signing any experimental publisher workflow.
